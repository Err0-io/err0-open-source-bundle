# One project per line. Lines starting with # are comments.
# Empty lines are ignored.
#
# Format: <project-directory-name>
#
# The project name should match:
# 1. The subdirectory name in the repository root
# 2. The project name in token files: err0-<project>-*.json
#
# To add a new project:
# 1. Add as git submodule: git submodule add <url> <project-name>
# 2. Add project name to this file
# 3. Generate token for project and place in tokens/
# 4. Update config/submodule-mappings.txt with public URL
